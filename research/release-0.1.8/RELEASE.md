## Чем проверено

- Собственные испытания: **47 pass, 0 fail, 3 not run**, обе линии (было 46).
- Стенд двух сред `research/028/dual_check.py`: **16 из 16** на обеих линиях — один вход, неизменность
  настроек сред, тождество при одинаковом и разном `environment`, конфликт правил в обе стороны,
  независимость от порядка сред, `second_entry`, чужая правка входа, заглушки, повторный проход.
- Проверка адаптера Copilot: 13 из 13 на обеих линиях (адаптер не сломан).
- Правило тождества не поехало: корпус 24 склейки, журналы 3 из 3, ложных 0 из 40 — на обеих линиях.
- Данные 0.1.7 читаются 0.1.8, чтением не переписываются.
- В обеих линиях поставки лежат `releases/0.1.0`, `0.1.4`, `0.1.5`, `0.1.6`, `0.1.7`, `0.1.8`.

## Чего не проверено

- Живой VS Code с двумя расширениями: загрузка `AGENTS.md`, старшинство наборов, что среды передают
  модели — уровни достоверности 2–4 и живые модели (И‑031, И‑032, И‑045).
- Заглушки — не адаптеры: у Claude Code, Cursor и Antigravity нет ни карточки фактов, ни обнаружения.
- Windows, ограниченные права, журналы заказчика.
