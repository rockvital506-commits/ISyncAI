# AgentContractKit 0.1.33 — права измерены

18 ноября 2026. Итерация **И‑053**, §4 п. 8–9 и §5. Линия выводится от неизменённого 0.1.0 теми же правками,
что дали 0.1.4–0.1.32.

## Что нового

- **`access`** (чтение, `writes: false`): для каждого из девяти путей записи — своя проба: файл
  `.agent-contract-probe-…` создаётся в каталоге пути, сбрасывается на диск и удаляется в той же операции;
- ответ: `paths` — `{writable, reason, errno}`, `all_writable`, `left`, `measured: true`, `probe`, `note`;
- причины: `null` (можно), `permission` (нет прав), `io` (иная ошибка ввода-вывода), `no_directory`
  (каталога пути нет — установка не выполнялась);
- `rights.note` теперь говорит прямо: объявление — не факт, факт даёт `access`;
- `access` в списке чтения, `repeat` его принимает; после вызова в проекте не остаётся ничего.

## Чего в выпуске нет

ACL и NTFS — `not run`: проверены биты прав POSIX. Смонтированный только для чтения диск и занятый файл
дают `io`/`EROFS` по коду, но отдельным случаем не имитировались. Промпт инициализации — И‑054,
калибровка — И‑055.
