# Указатель исследований

Для текущей разработки **DomainAgentKit** действующий роадмап —
[`kilo/ROADMAP.md`](kilo/ROADMAP.md) v3.0.0. Прочитайте его до работы и сверяйте после каждой
итерации. Он содержит решения владельца о донорах, областях и проверке; журнал изменений —
[`kilo/MVP-ROADMAP.md`](kilo/MVP-ROADMAP.md).

[`STRATEGY.md`](STRATEGY.md) v1.23 и [`ROADMAP.md`](ROADMAP.md) в этом каталоге — исторические
артефакты. Их сохранённые требования действуют лишь в пределах, установленных текущим роадмапом;
не переписывайте их печати. Историческая матрица `strategy/COMPATIBILITY.json` не предписывает
миграцию донора в целевой Kit. Исследования ISAI — отдельная тема, а не архитектура Kit.
