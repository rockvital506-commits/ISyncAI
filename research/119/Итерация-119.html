Подпись и исключение не заменяют целостность

П5 принята на синтетических данных

Отсутствие подписи — не повреждение. Действительное исключение не исправляет пакет и не делает его подписанным.

Рабочая копия51 pass / 0 fail / 0 not run
Чистая копия51 pass / 0 fail / 0 not run
Ворота приёмки12 pass / 0 fail / 4 not run

Что различила проверка

Подпись

Две настоящие подписи Ed25519 проверены OpenSSL. Перенос подписи к ZIP с пересчитанным манифестом не проходит.

Исключение

Только для unsigned, одного SHA‑256 ZIP и разрешённого approver. Ровно в expiry уже не действует.

Целостность

2 подмены остановлены до решений. Пакет с неверными байтами не может воспользоваться исключением.

Решение относится только к переданной политике. Это не установка, не рабочий перенос и не доказательство защищённости источника ключей или часов.
