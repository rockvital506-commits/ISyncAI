# AgentContractKit 0.1.22 — кто вправе менять правило

18 ноября 2026. Итерация **И‑042**, §10.1. Линия выводится от неизменённого 0.1.0 теми же правками,
что дали 0.1.4–0.1.21.

## Что нового

- у правила может быть владелец: необязательное поле `owner` — строка до 64 символов, `null` — общее правило;
- `edit`, `transition` и `purge` у правила с владельцем требуют `actor`, равный владельцу, иначе отказ
  `not_owner` с `{owner, actor}`;
- передача владения (включая назначение владельца общему правилу) требует `allow_owner: true`, иначе
  отказ `owner` с `{from, to}`;
- общее правило (`owner: null`) правит любой, `actor` для него не нужен;
- схема не ужесточена: записи 0.1.21 без `owner` читаются и чтением не переписываются.

## Чего в выпуске нет

Проверки личности `actor` (комплект фиксирует, от чьего имени пришла правка), живой среды VS Code с Kilo и
Copilot, прав Windows, журналов заказчика, метрик и миграции — они впереди (И‑043…И‑050).
