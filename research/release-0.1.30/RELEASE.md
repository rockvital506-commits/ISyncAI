# AgentContractKit 0.1.30 — чужая файловая система

18 ноября 2026. Итерация **И‑050**, §16. Линия выводится от неизменённого 0.1.0 теми же правками, что
дали 0.1.4–0.1.29.

## Что нового

- **`system`** — чтение без записи: `case_insensitive` **измерено** чтением соседнего имени (без записи),
  `declared` — лимиты (260/4096, 255 байт на имя, зарезервированные имена Windows, юникод), `proven` —
  что из этого на этой машине измерено, а что объявлено;
- **отказ `case`** — имя совпадает с существующим без учёта регистра: на NTFS это один файл, и «создать
  рядом» значит «перезаписать»; в деталях `{path, existing}`;
- **отказ `path`** — компонент длиннее 255 байт в UTF-8 (`{part, bytes, limit}`), до записи;
- **`rights.files`** — измеренные права файлов проекта: `mode`, `world_writable`, `bytes`; на Windows
  режим остаётся `null`, а не выдуманным.
