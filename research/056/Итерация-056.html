Находка F70. Якорь без проверки — украшение, а не ссылка. Стоило тесту разрешать каждый якорь, как первая же сборка нашла три мёртвых: releases/0.1.35 до копирования цепочки, оглавление и примеры формата в таблице.
Находка F71. README-журнал разрастался линейно: 34 530 B к 0.1.35, из них 27 800 — разделы «Что изменилось». Вектор занял 19 871 B и стал полнее: раньше в README не было ни «Чего нет», ни таблицы команд. История выпусков не потеряна — она в releases/*/PROTOCOL.md и PROTOCOL.md.
Находка F72. «Чего нет» нельзя писать по памяти: список not run определяется прогоном. Сборка сверяет коды из CHECKS.json с трассировкой, поэтому обещание «всё проверено» физически не проходит.
Находка F73. Список уровней в трассировке — второй реестр, если писать руками. Стенд сверяет уровни по собственному паспорту: первая же попытка задать L1…L10 списком поймала 13 расхождений — уровни называются L4W, L5a, L4K.
Чего нет. Проверки «человек прочитал и понял» — not run: проверены якоря и покрытие, а не понимание. Ответы живой модели, VS Code с расширениями и ACL/NTFS — тоже not run.
