## Чем проверено

- Собственные испытания: **42 pass, 0 fail, 3 not run**, обе линии (было 38 в 0.1.5).
- Независимая проверка адаптера (`research/026/adapter_check.py`): 11 из 11 на обеих линиях —
  карточка, отказ неизвестной среды, шесть раскладок Kilo, порядок подтверждения, отсутствие записи
  в среду по всему дереву, отсутствие заявленного обнаружения.
- Правило тождества не поехало: корпус 24 склейки (12 + 12 объявленных в И‑025), журналы 3 из 3,
  0 ложных из 40 — на обеих линиях.
- Данные 0.1.5 читаются 0.1.6, чтением не переписываются.

## Чего не проверено

- Живой Kilo Code: загрузка входа в редакторе, реальное старшинство `instructions` против `AGENTS.md`,
  чтение содержимого агентом — уровни достоверности 2–3 (И‑030…И‑032) и живые модели (И‑045).
- Windows, ограниченные права, журналы заказчика.
