# AgentContractKit 0.1.29 — права: кто читает и кто пишет

18 ноября 2026. Итерация **И‑049**, §11. Линия выводится от неизменённого 0.1.0 теми же правками, что
дали 0.1.4–0.1.28.

## Что нового

- **`rights`** — чтение без записи: `reads` (что комплект читает), `write_paths` (закрытый список, куда
  пишет), `never` (чего не касается), `roles` (кто здесь писатель), `foreign` (посторонние файлы);
- **посторонняя запись останавливает изменения**: файл в `.agent-contract/`, которого комплект не создавал,
  даёт отказ `foreign` с перечнем на `plan`/`apply`; чтение продолжает работать, `restore`/`undo` не
  блокируются;
- **`status.foreign`** называет посторонние файлы при чтении;
- **`metrics`, `due`, `rights` входят в список чтения**: `repeat` принимает их наравне с прочими чтениями
  (раньше отказывал кодом `repeat_write`).

Границы не расширяются: закрытый список тот же (9 путей), схема та же, чтение по-прежнему не пишет.

## Чего в выпуске нет

Живых прав файловой системы (ACL, POSIX-режимы, NTFS): стенд подаёт платформу как объявленные данные.
Разделения читателей комплект не делает — он не различает, кто читает. Windows и живые модели впереди
(И‑050, И‑051).
