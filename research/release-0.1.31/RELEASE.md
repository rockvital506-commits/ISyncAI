# AgentContractKit 0.1.31 — живые модели

18 ноября 2026. Итерация **И‑051**, §14 уровень 4. Последний выпуск линии комплекта. Линия выводится от
неизменённого 0.1.0 теми же правками, что дали 0.1.4–0.1.30.

## Что нового

- **`model`** — карточка живой части: три задачи (`explain`, `choose`, `refuse`), формат записанного ответа,
  каталог `.agent-contract/local/model/*.json` (пишет владелец, комплект сюда не пишет), оценка каждой
  записи и уровни: `4_behavior_checked` — измерен по записям, `3_read_by_model` и `5_behavior_repeatable`
  — `not run`. `live: false` сказано прямо: комплект модель не вызывает;
- **`verify`** — оценка одного ответа как данных: утверждение `{id, state, text}` сверяется с машиной
  состояний. Ответы: `same`, `state_mismatch` (включая `hidden` — правило `active` под неактивным
  контрактом), `text_mismatch` (сравнение по словам), `unknown_rule`. Пустой ответ или утверждение без
  `id` — отказ `answer`;
- **список чтения:** `model` и `verify` — чтения, `repeat` их принимает, проект не меняется;
- **`rights.inputs`** называет записанные ответы входом владельца, а не записью комплекта.
