- **Стенд обкатки** `pilot.py`: тот же сценарий владельца, но P3 проверяется переключением наблюдателя
  (Kilo → Copilot), а P4 — настоящим конфликтом git и операцией `merge`. Матрица **6 pass / 2 fail** на
  обеих линиях (было 4 / 4): закрыты P3, P4, P7. Остались P5 (первый промпт) и P6 (`docs/`).
- **Корпуса через консоль**: пунктуация 12/12, И‑029 80/80, 112 пар — 24 склейки, прочих 0; байты при
  склейке не меняются. Правило тождества не менялось — числа те же, что в 0.1.12.
- **Журналы** (прежний стенд): 3 из 3 повторов, ложных 0 из 40.
- **Совместимость**: данные 0.1.12 читаются 0.1.13 и чтением не переписываются; повтор записи байты не
  меняет.
- Собственные испытания: **57 pass, 0 fail, 3 not run**, обе линии.
- Приёмка И‑033: **10 pass / 0 fail / 5 not run**; печать `AgentContractKit-Iteration-033.zip`
  (43 члена, 647 486 B, `0bd23dc1…`), повтор `identical: true`.

## Что осталось

| Пункт | Суть | Итерация |
|---|---|---|

Находка F14: `merge` добавляет записи, но не сводит разногласия одного события — входящая запись с
другим исходом отбрасывается как дубль. Это объявленное ограничение решения Б, а не недосмотр.

## Чего не проверено

- Живые VS Code, Kilo и Copilot; загрузка инструкций средой.
- Поведение моделей: `environment` объявляется вызывающим, а не измеряется (F13).
- Слияние на истории владельца: проверен синтетический конфликт одного файла.
- Права, настоящий NTFS, журналы заказчика.
