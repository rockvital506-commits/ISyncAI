| Файл | Изменение |

## Чем проверено

- Собственные испытания: **38 pass, 0 fail, 3 not run, 0 inconclusive**, обе линии (было 35 в 0.1.4).
- Настоящие журналы (стенд И‑023, 43 пары): склеено 3 повтора из 3, ложных склеек 0 из 40 — было 0 из 3.
- Корпус 112 пар (И‑024): 12 форменных склеек сохранены, 64 прочих отказа сохранены, 12 пар «изменён файл свидетельства» теперь склеиваются — **объявленное изменение спецификации**, ожидание И‑024 не переписано (см. `research/025/EXPECTATIONS.json`).
- Данные 0.1.4: файл наблюдений читается, чтением не переписывается, повтор не меняет байты, другой счётчик пишет запись.
- Сквозная имитация и ведомость отпечатков — в отчётах поставки.

## Чего не проверено

- Обновление проекта на месте командой `update` (трёхстороннее сравнение с разрешениями конфликтов).
- Журналы заказчика, Windows, ограниченные права, живые модели.
- Цена отменённой защиты «подмена файла свидетельства» на настоящих журналах: подходящего настоящего случая нет.
