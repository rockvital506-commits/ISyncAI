# Сколько итераций осталось

Ответ на вопрос «сколько ещё итераций, выделенных из ISAI-контрактов, правил, настроек, протоколов и их самостоятельных элементов».

**Единица счёта** — один независимый элемент: одна проверяемая поверхность с собственным входом и собственным прогоном (замысел до прогона → стенд → серия → приёмка → отчёт → печать → повтор → решение). Два элемента не склеиваются в одну итерацию, если у них разные входы, разные коды отказа или разные условия приёмки.

## Короткий ответ

|---|---:|---|
| Закрыто циклом 001–021 | 21 | 001–021 |
| Всего в карте | 57 | И‑022 … И‑078 |
| **Осталось всего** | **49** | И‑030 … И‑078 |
| — по переносимому комплекту (Kit) | 16 | И‑030 … И‑045 |
| — по ядру ISAI (`.isai/`) | 33 | И‑046 … И‑078 |
| Ближайшие три | 3 | И‑030, И‑031, И‑032 |

Номера в этой таблице выправлены в И‑027: раньше адаптер Antigravity и «уровень достоверности 2» делили номер И‑030, из-за сдвига после И‑025 счёт «осталось» показывал 57 при 57 занятых номерах. Теперь номера уникальны, а «осталось» считается от закрытых.

Оценка ±20 %: элементы выделены по коду и по донорскому документу, но объём каждого проверяется на стенде и может дать одну-две дополнительные итерации на находки.
