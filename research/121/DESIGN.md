## Гипотеза и границы формата

Матрица `SURFACES.json` формата 1 — данные исследования, не адаптер, команда или новый реестр. `validate_surfaces(raw, *, baseline, report_rank)` принимает UTF‑8 JSON в `bytes` (до 96 КиБ) и два явных локальных исторических свидетельства. Возвращает сводку того, что указано в матрице, либо код с фиксированной областью. Валидатор не открывает перечисленные пути, не запускает клиентов или инструкции и не имеет сети. Смысл свободного текста не проверяется автоматически: `basis` и `criterion` показывают, с чем сверить факт или что измерять дальше.

- Ровно шесть строк. У Arena Agent Mode, Kilo в VS Code и GitHub Copilot в VS Code текущий `status: candidate`. Это не `documented`, не `empirical` и не «работает». Имена входов из стратегии — только кандидаты: `AGENTS.md` в копии Arena, `AGENTS.md`/`kilo.jsonc`/`.kilo/rules` у Kilo, `AGENTS.md` и общие/путевые инструкции `.github` у Copilot. Точный ключ Kilo, версия и режим реальной пробы не подставляются. План Windows 11 / VS Code 1.146 — план пилота, не наблюдение. Ручной кандидат — первый согласованный запрос с явным адресом `kit/base/entry.txt` к `START.md §0`; не свидетельство автоматического обнаружения.
- Claude Code, Cursor и Antigravity сохраняют `status: stub` с причиной, без активного входа, ручной команды, следующего опыта или разрешения. Их ячейки вне области. Кандидаты имеют пять раздельных `not run`: наличие входа **в целевой пробе**, обнаружение клиентом, чтение, применение, повторяемость. Запусков 0, доли `read_rate`, `apply_rate`, `false_positive` — `null`, не нули. `AGENTS.md` в исходном checkout не заполняет ни одну из этих ячеек. Ни одну ячейку «среда × операция» И‑121 не принимает; разбиение И‑125 по P12 — отдельно до прогона.
- Ни для кого не выбран победитель по старшинству, нет числового ранга цели. «Nearest wins», порядок Kilo и обнаружение в sandbox — гипотезы; для конфликтов планируются сравнимые пробы. Не подменяем A1–A4 правилами клиента и не предлагаем второй реестр. Кап 25–30% окна — цель Kit (P8, И‑126); 4096 B — предел локального читателя §0 (И‑112/S05). Это не клиентские лимиты: байты, токены и проценты разделены; измеренных капов клиентов здесь нет.
- Для каждой строки: что не трогаем, явные пробелы с основанием и критерием (И‑122 — Kilo и `foreign` без перезаписи, И‑123 — Copilot и конфликт, И‑124 — Arena и граница копии/PR в будущем опыте, И‑125 — чтение/применение, И‑126 — бюджет). До матрицы и валидатора: независимые ожидаемые шесть строк, выбранные поля исходного ориентира, открытые исторические наблюдения и отрицательные случаи.
