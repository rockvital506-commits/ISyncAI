что дали 0.1.4–0.1.35.

## Что нового

- **`README.md` переписан как вектор смысла**: три входа (пользователь / агент / проверяющий), границы,
  смыслы файлов, команды и раздел «Чего нет»; объём **19 871 B** (лимит 24 КБ, было 34 530 B);
- **якоря**: каждое нормативное утверждение заканчивается ссылкой `[START: фраза]`, `[PROTOCOL: фраза]`,
  `[INIT: фраза]`, `[КАЛИБРОВКА: фраза]`, `[X84]`, `[K2]`, `[manifest]`, `[TRACE]`; 60 различных якорей,
  мёртвых 0;
- **`TRACEABILITY.json`**: §2…§18 → тема → артефакты → испытания → уровни → `covered`; 17 разделов;
- **`X87`** (лимит 24 КБ, каждый якорь разрешается, утверждений без якоря нет), **`X88`** (§2…§18 покрыты,
  артефакты и испытания существуют), **`X89`** («Чего нет» = фактический список `not run` отчёта);
- **сборка падает**, если якорь ведёт в никуда, если раздел не покрыт или если README обещает больше, чем
  измерено;
- **уровень обкатки L10**: README прочитан как данные, трассировка сверена по паспорту стенда.
