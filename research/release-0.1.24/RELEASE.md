# AgentContractKit 0.1.24 — миграция при неизвестной версии

18 ноября 2026. Итерация **И‑044**, §12.2. Линия выводится от неизменённого 0.1.0 теми же правками, что
дали 0.1.4–0.1.23.

## Что нового

- **неизвестная версия схемы — свой код**: отказ `unknown_schema` с деталями `{found, supported, migrate,
  recover}` — что найдено, что поддерживается, возможна ли миграция и чем вернуться;
- **проверка версии идёт до проверки формы**: «не число», «чужая версия» и «своя в неверной форме» больше
  не сливаются в один код;
- **миграция не угадывает**: `migrate` на версии вне 0 → 1 отклоняется тем же кодом и ничего не пишет;
  поддерживается только явный обменный формат 0 → 1;
- **данные не переписаны**: отказ выдаётся до записи, чтение с неизвестной схемой оставляет проект байт в
  байт;
- **путь назад назван честно**: копия проекта или `local/ops/<tx>/before/.agent-contract/project/state.json`,
  равный прежнему состоянию.

## Чего в выпуске нет

Комплект не мигрирует чужие схемы и не откатывает их: возврат — копия проекта или файл `before`. Проверки
личности `actor`, живой среды (VS Code с Kilo и Copilot), прав Windows, журналов заказчика, метрик и
частичного сбоя в выпуске нет — они впереди (И‑045…И‑050).
