# И‑053 · Права: измеренные и объявленные — замысел до прогона

18 ноября 2026. Выпуск **0.1.33**. Вторая итерация фазы «пригодность к применению».

## В чём трудность

`rights` с 0.1.29 называет закрытый список из девяти путей записи. Это данные — договорённость о том, куда
комплект вправе писать. Факт другой: каталог может быть только для чтения, диск смонтирован `ro`, файл занят
другой программой.

| Что | До 0.1.33 | Чем плохо |
|---|---|---|
| право писать | объявлено списком | список говорит «можно», а `open` в этот момент — нельзя |
| причина отказа | не называлась | падение в середине операции, а не отказ заранее |
| каталог только для чтения | обнаруживался по факту сбоя | «пригодно к применению» выяснялось после попытки |
| что делать | не сказано | непонятно, чьи это права — ОС, пользователя, раскладки |

## Что появляется в продукте

`access` (чтение, `writes: false`): для каждого из девяти путей в каталоге **самого пути** создаётся свой
временный файл `.agent-contract-probe-…`, пишется, сбрасывается на диск и удаляется в той же операции.

Ответ: `paths` — `{путь: {writable, reason, errno}}`, `all_writable`, `left`, `measured: true`, `probe`, `note`.
Причины: `null`, `permission`, `io`, `no_directory`.

## Решение, требующее внимания

В разборе дополнений было записано: пробная запись — **внутри `.agent-contract/`**. При реализации это
оказалось неверным для `AGENTS.md`: его каталог — корень проекта, и проба внутри служебного каталога
ответила бы «можно» там, где корень закрыт на запись. Поэтому проба идёт в каталоге каждого пути; для
`AGENTS.md` — в корне проекта, файл живёт миллисекунды и удаляется в той же операции, `left` это проверяет.
Это ровно тот риск, который в §7 назван «`access` врёт про права».

## Приёмка: что считается провалом

Провал — если `access` пишет в проект и оставляет файлы; если на каталоге только для чтения он отвечает
`writable: true`; если причина отказа не названа; если `access` меняет проект или не принимается `repeat`.
