# И‑053 · Права: измеренные и объявленные — отчёт

18 ноября 2026. Выпуск **0.1.33**. Право писать стало фактом, который измеряется, а не обещанием в списке.

## Что появилось

| Правило | Ответ |
|---|---|
| `access` | `paths` по девяти путям: `{writable, reason, errno}`; `all_writable`, `left`, `measured: true` |
| проба | файл `.agent-contract-probe-…` в каталоге самого пути: создаётся, сбрасывается на диск, удаляется в той же операции |
| причины | `null`, `permission`, `io`, `no_directory` |
| границы | `writes: false`; данные проекта не читаются и не меняются; право ОС комплект не выдаёт и не обходит |
| `rights` | `note` теперь говорит: объявление — не факт, факт даёт `access` |
| чтение | `access` в списке чтения; `repeat` его принимает |

## Уровень L4W: что именно измерено

| Шаг | Измерено |
|---|---|
| `access` на установленном проекте | 9 путей, `all_writable: true`, `writes: false`, `left: []`, проект байт в байт прежний |
| файлы пробы после вызова | не осталось ни одного (`.agent-contract-probe-*` — 0) |
| `chmod 555` корня проекта | `AGENTS.md` → `writable: false`, `reason: permission`, `errno 13`; `all_writable: false` |
| файлы внутри `.agent-contract/` | остались `writable: true` — права измеряются по каталогу каждого пути, а не по проекту целиком |
| `repeat` (`access` ×2) | `identical: true`, проект не изменён |

Проверка «`access` врёт про права» из §7 выполнена по существу: на закрытом каталоге ответ отрицательный,
и это ответ на вопрос про конкретный путь, а не про проект.

## Находки

- **F60.** Право — это факт с моментом времени. Список `write_paths` отвечает «куда комплект вправе писать»,
  `access` — «куда он может писать сейчас». Пока эти два ответа не различались, «пригодность к применению»
  проверялась попыткой записи, то есть уже после согласия владельца.
- **F61.** Проба внутри служебного каталога неверна для `AGENTS.md`: его каталог — корень проекта. Ответ
  «можно» там, где корень закрыт, был бы ровно тем враньём, от которого защищает §7. Проба идёт в каталоге
  каждого пути, имя своё, файл удаляется в той же операции, `left` и тест X80 проверяют, что следов нет.
- **F62.** Отказ по правам должен быть отказом заранее. С `access` последовательность «проверить → согласиться →
  выполнить» стала возможной: владелец видит `writable: false` до того, как комплект начнёт писать.
