Находка F60. Право — это факт с моментом времени. write_paths отвечает «куда комплект вправе писать», access — «куда он может писать сейчас». Пока эти ответы не различались, пригодность проверялась попыткой записи, то есть уже после согласия владельца.
Находка F61. Проба внутри служебного каталога неверна для AGENTS.md: его каталог — корень проекта. Ответ «можно» там, где корень закрыт, был бы ровно тем враньём, от которого защищает §7. Поэтому проба идёт в каталоге каждого пути; имя своё, файл удаляется в той же операции, следы проверяются (left, тест X80).
Находка F62. Отказ по правам стал отказом заранее: последовательность «проверить → согласиться → выполнить» теперь возможна, и владелец видит writable: false до того, как комплект начнёт писать.
Чего нет. ACL и NTFS — not run: проверены биты прав POSIX и chmod. Смонтированный только для чтения диск и занятый файл дают io/EROFS по коду, но отдельным случаем не имитировались. Живая среда VS Code и поведение моделей — not run.
