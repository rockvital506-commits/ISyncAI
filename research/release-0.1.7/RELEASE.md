## Чем проверено

- Собственные испытания: **46 pass, 0 fail, 3 not run**, обе линии (было 42 в 0.1.6).
- Независимая проверка адаптера (`research/027/adapter_check.py`): **13 из 13** на обеих линиях —
  карточка, четыре отказа `second_entry`, работа с `AGENTS.md` без появления `.github/`, семь раскладок
  Copilot, порядок подтверждения, отсутствие записи в среду по всему дереву, отсутствие заявленного
  обнаружения.
- Правило тождества не поехало: корпус 24 склейки (12 + 12 объявленных в И‑025), журналы 3 из 3,
  0 ложных из 40 — на обеих линиях.
- Данные 0.1.6 читаются 0.1.7, чтением не переписываются.

## Чего не проверено

- Живой Copilot / VS Code: загрузка `AGENTS.md` и файлов инструкций, реальное старшинство наборов,
  Chat на github.com и inline suggestions — уровни достоверности 2–4 (И‑031, И‑032, И‑045).
- Windows, ограниченные права, журналы заказчика.
- `excludeAgent` во front matter path-specific файлов: комплект такие файлы не пишет, поле вне предмета.

## Исправление (найдено в И‑028)

В опубликованном архиве 0.1.7 лежали только `releases/0.1.0` и `releases/0.1.7`: предыдущие выпуски
не попали в поставку, потому что сборка копировала их из дерева прошлой сборки, а оно живёт только до
конца хода. Трёхстороннее обновление с 0.1.5 или 0.1.6 на 0.1.7 поэтому не имело исходного выпуска
внутри поставки. Выпуск 0.1.8 восстанавливает цепочку `0.1.4`–`0.1.7` из опубликованных архивов;
байты 0.1.7 не менялись, здесь только запись о находке.
