# Карточка RECIPE-DRYRUN · прохождение `INSTALL-KILO.md` на чистом проекте

**Тип:** проверка продуктового документа (не проба поведения Kilo, а проверка инструкции)
**Дата:** ____ · **Стенд:** `D:\kilo-stand-122\p9` — **пустая папка**, ничего из p1–p8 не копируем
**Состояние:** мастер автоодобрения **ВЫКЛ**, агент `Code`, модель `Auto Free`

## Замысел (до)

- **Гипотеза:** документ `INSTALL-KILO.md` проходится человеком **с нуля**, без подсказок агента,
  и каждый шаг имеет проверку, по которой видно «получилось / нет».
- **Эталон:** пять шагов пройдены, шаг 5 даёт цитату **и** строку `Instructions from:`, нигде не пришлось
  догадываться, что делать.
- **Допустимое:** шаг требует уточнения формулировки → это правка **документа**, а не провал.
- **Критическое:** документ обещает проверку, которой нет; шаг выполнен, а результата не видно; раздел
  «что НЕ обещают» противоречит наблюдению.
- **НЕ проверяем:** поведение Kilo (оно уже измерено) — только **качество инструкции**.

## Важно: это не новая проба Kilo

Мы проверяем **документ для человека**. Поэтому результат — не «pass/fail пробы», а
**список правок в текст**: где непонятно, где не хватает шага, где проверка бесполезна.

## Подготовка

1. Создайте **пустую** папку `D:\kilo-stand-122\p9` (без `.kilo`, без `kilo.jsonc`, без `AGENTS.md`).
2. `Файл` → `Открыть папку…` → `p9`.
3. Проверьте: щит **выключен** (подсказка «Автодобрение отключено»).

## Прохождение

Дальше — **строго по документу** `research/kilo/INSTALL-KILO.md`, ничего не додумывая.
Держите документ открытым рядом.

После **каждого** шага отметьте три вещи:

| Отметка | Значение |
|---|---|
| **сделал** | что именно вы сделали (одна строка) |
| **видно** | что показал экран на проверке из этого шага |
| **заминка** | что пришлось додумать или поискать — даже мелкое |

## Что прислать

```
шаг 1 — сделал: …, видно: …, заминка: … (или «нет»)
шаг 2 — …
шаг 3 — …
шаг 4 — …
шаг 5 — ответ агента: <дословно>; есть ли строка Instructions from: да/нет
общее время: N минут
самое непонятное место в документе: <цитата или шаг>
```

## Как я прочитаю результат

| Что увижу | Правка документа |
|---|---|
| заминка на шаге N | переписать формулировку шага N или добавить проверку |
| «видно: ничего» | проверка шага бесполезна — заменить на наблюдаемую |
| шаг 5 без `Instructions from:` | проверить, не сработало ли правило «случайно» |
| всё прошло без заминок | документ готов; отмечаю как пройденный |

**Заминки — это не ваша ошибка.** Каждая заминка = место, где документ неполон. Именно за ними и идём:
инструкция, которую нельзя пройти не думая, — плохая инструкция.

## Чего я НЕ буду делать с результатом

- Не буду править документ «на глаз»: сначала запишу все заминки, потом внесу правки одной правкой.
- Не буду считать «прошёл, потому что я уже знаю, как должно быть» — важно именно прохождение **по тексту**.
