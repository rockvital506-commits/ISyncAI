## Если сеанс не стартует

| Симптом | Причина | Действие |
|---|---|---|
| «выберите модель» | модель не выбрана | Настройки → Модели → выбрать конкретную |
| ошибка авторизации | провайдер не подключён | Настройки → Провайдеры → подключить |
| бесконечная загрузка | CLI-сервер не поднялся | «Перезагрузить» в шапке настроек |
| ошибка SQLite | повреждена локальная база | `kilo db path`, действовать по документации, вручную не удалять |

Записать текст ошибки дословно — это и есть результат `E16`.
