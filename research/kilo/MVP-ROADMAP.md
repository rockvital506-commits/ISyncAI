# Журнал MVP и сверок

**Действующий роадмап:** [`ROADMAP.md`](ROADMAP.md), версия 3.1.0. Этот файл — журнал и
исторический маршрут MVP, не альтернативный финал. Старые записи оставлены как свидетельства
своего времени; их планы и выводы не перекрывают решения владельца в действующем роадмапе.
Особенно: этапы 8а–8в про донорскую миграцию не являются обязательным маршрутом. Стратегия
v1.23 сохраняется в исторических байтах из-за печати И-121. MVP не является релизом 0.2.0.

Постоянный принцип владельца: эффективная мутация — искать кратчайший допустимый путь к целевым
возможностям с учётом фактических границ среды. Не заменять цель удобным приближением; неизвестное
отмечать `not run`. При критическом расхождении, необходимости новых прав или изменения финала — стоп.
Владелец разрешил самостоятельно разрабатывать, проверять и публиковать текущую работу в текущей
ветке; не разрешены повышение прав, глобальные настройки и работа с чужими проектами.

| Этап | Результат | Состояние |
|---|---|---|
| 0 | живой аудит актуального ядра с ограничениями | принят владельцем; старые 20 расхождений остаются |
| 1 | кандидат поставки и карта слоёв | выполнен в исходном дереве; не релиз |
| 2 | реальные переносимые записи L1 | черновики подготовлены; активация в ядре реализована, реальный профиль не утверждён |
| 3 | безопасное преобразование записи в материал для среды | выполнен preview только для scope `.`, без установки |
| 4 | изолированные синтетические проекты и проектные правила | синтетические примеры и проверки выполнены; реальные проекты not run |
| 5 | сквозная проверка; Arena — самостоятельно, Kilo — владелец | синтетический путь проверен; создание одного нового файла Kilo — экспериментальная поверхность, живые среды not run |

Каждая самостоятельная поверхность получает запись до и после. Результат разработки отличается от
проверки живой среды: наблюдения Kilo выполняет владелец по отдельной карточке, пауза между пробами.
Никакая запись в этом журнале не пересобирает исторические архивы или не меняет финал.
