# Исследование нового пустого контейнера после неопределённого исхода `.77a`

`research/audit/release_rebuild_study.py` — исследовательский Python API, **не восстановление
пользовательских данных**. В ситуации с неизвестной старой установкой он показывает наблюдение
только указанных старой цели и сохранённого имени стадии, а затем строит план создания полностью
нового пустого контейнера в явно указанном другом существующем родителе. L0 берётся из заново
проверенного архива, L1/L2 пусты. История, изменённые L1/L2 и файлы пользователя **не
читаются, не копируются и не восстанавливаются**. Старые объекты не удаляются и не изменяются
этим кодом. Это может создать второй экземпляр и не устанавливает, какой из них действующий.

Полный план содержит старое наблюдение, все имена и хеши нового состава, оба назначения,
непроверенное происхождение и отдельный билет. Только отдельное подтверждение полного плана
допускает новую запись. Проверяются различие буквальных путей, отсутствие вложенности и разные
идентичности inode родительских каталогов. Перед записью наблюдение повторяется и при его
изменении план отвергается. Состояние не атомарно: совпадение наблюдения не доказывает
отсутствие промежуточных изменений, чужих писателей, mount-алиасов или изменение происхождения.
Оно не удостоверяет согласие, фактическое завершение старой установки и сохранность данных.

Для новой публикации действуют ограничения `.76`: доверенные инструменты/политика/ключи
предполагаются; нет защиты от некооперативных писателей и отказа питания. При неопределённом
исходе нельзя удалять или повторять ни старую, ни новую стадию вслепую. Эти пробы не являются
планом удаления, слияния, rollback, восстановления истории или реальной приёмкой `.77`.
API вызывается только из синтетических тестов; человеко-машинный интерфейс для этой операции
не создан. Реальные данные и состояния остаются за пределами проверок.

`python3 -I -S -B research/audit/test_release_rebuild_study.py -v`: искусственная неудача
rename исходной стадии; отдельная реконструкция; проверки старого дерева до и после; отмена,
подмена плана, изменённое наблюдение, занятая цель, совпадающий/вложенный путь, повтор билета
и ошибка rename нового дерева. Это программные пробы, не физическое выключение питания.
