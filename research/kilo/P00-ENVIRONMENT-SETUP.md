# P00: подготовка среды перед пробами (обязательный шаг, не проба)

**Зачем:** проба без настроенной среды измеряет не то. Ниже — что настроить, зачем, чем рискуем и
как проверить, что готово. Всё делается **в VS Code у вас**, я не имею доступа к вашей машине.

**Правило:** ничего из этого не является доказательством поведения Kilo. Это подготовка состояния.

---

## Шаг 1. Зафиксировать версии (2 минуты)

| Что | Где | Куда записать |
|---|---|---|
| VS Code 1.147.0 | Справка → О программе | `VSCODE_VERSION` |
| Kilo 7.8.32 | Kilo → шестерёнка → «О Kilo Code» → «Информация о версии» | `KILO_VERSION` |
| CLI-сервер | там же: «CLI-сервер: Подключено, порт 4896» | `CLI_STATUS` |

**Проверка готовности:** три значения записаны. Без них пробы не имеют смысла — версия может
смениться сама (автообновление включено).

**Риск:** автообновление. Если версия изменится между пробами — результаты несравнимы. На время проб
автообновление Kilo лучше выключить (галочка «Автоматическое обновление» на странице расширения).

## Шаг 2. Подключить провайдера и выбрать модель (5–10 минут)

**Зачем:** сейчас «Подключённые провайдеры: нет», модели `kilo-auto / free`. Пока провайдер не
подключён, сеанс может не стартовать — тогда все пробы упираются в `E16`, а не в Kilo.

**Как:**

1. Kilo → шестерёнка → **Провайдеры**.
2. Вариант A (проще): **Kilo Gateway** → «Подключить» → вход по устройству/коду.
3. Вариант B: свой ключ у Anthropic/OpenAI/Google → «Подключить» → вставить ключ.
   **Ключ вводится только в интерфейсе Kilo, не в `kilo.jsonc` и не в проекте.**
4. **Модели** → «Модель по умолчанию» → выбрать конкретную модель с известным окном
   (например, модель Claude или GPT с явным размером контекста).

**Почему важен явный размер окна:** если модель не объявляет `limit.context`, автосжатие
**не работает** (правило из документации Kilo). Тогда проба П8 измеряет не поведение, а отсутствие
настройки. Это уже зафиксировано как `E16`.

**Проверка готовности:** в «Провайдерах» появился подключённый провайдер; в «Моделях» выбрана
конкретная модель, а не «Не задано».

## Шаг 3. Явно зафиксировать права (3 минуты)

**Зачем:** сейчас действует пресет «Сначала проверка» (`bash ask`, `edit ask`, `read allow` без
`.env`). Для проб нужно знать точку отсчёта, иначе непонятно, что изменилось.

**Как:**

1. Настройки → **Автодобрение**. Сфотографировать экран целиком.
2. Записать: мастер автоодобрения (вкл/выкл), и значения для `bash`, `edit`, `read`, `task`.
3. **Не менять** ничего на этом шаге. Меняем только в П5/П7, где это предмет пробы.

**Проверка готовности:** есть фото или список значений до начала проб.

## Шаг 4. Проверить, что сеанс вообще стартует (2 минуты)

1. Открыть панель Kilo Code (иконка в Activity Bar).
2. Выбрать агента **Code**.
3. Написать: «ответь одним словом: готов».
4. Ожидаемо: ответ модели.

**Если ответа нет:**

| Симптом | Что значит | Что делать |
|---|---|---|
| «выберите модель» | модель не выбрана | шаг 2 |
| ошибка авторизации | провайдер не подключён | шаг 2 |
| бесконечная загрузка | CLI-сервер не поднялся | «Перезагрузить» в шапке настроек |
| ошибка SQLite | повреждена локальная база | `kilo db path`, см. документацию; **не** удалять вручную |

**Это и есть проверка `E16`.** Если сеанс не стартует — записываем и останавливаемся: И‑122 в этот
день не идёт.

## Шаг 5. Отключить то, что помешает измерению (2 минуты)

| Что | Почему | Как |
|---|---|---|
| Автодополнение Kilo | уже выключено в вашем `settings.json` (`enableAutoTrigger=false` и др.) — **проверить, что так и осталось** | Настройки → Автодополнение |
| Copilot | вторая агентская среда в том же редакторе; мешает понять, кто ответил | отключить на время проб (не удалять) |
| Телеметрия Kilo | не влияет на поведение, но вы сказали — данные важны | Настройки → О Kilo Code → Телеметрия (по желанию) |

**Проверка готовности:** Copilot не отвечает в чате; автодополнение Kilo выключено.

## Шаг 6. Создать стенд с копиями проекта (5 минут)

Подробно — `STAND-COPY.md`. Коротко: три папки `p1`, `p2`, `p3` в отдельном каталоге, **не** внутри
рабочего репозитория.

## Шаг 7. Записать отпечаток P00

```
P00 | версии: VSCode=1.147.0, Kilo=7.8.32, CLI=подключён 4896
    | провайдер: <имя>, модель: <имя с окном>
    | права до: мастер=<вкл/выкл>, bash=<...>, edit=<...>, read=<...>, task=<...>
    | сеанс: стартует / не стартует (<ошибка>)
    | стенд: <путь к p1,p2,p3>
```

Это единственная «сводная» запись. Дальше каждая проба — отдельно.

## Чего в P00 нет

- Правки глобальных настроек редактора.
- Работы в чужих проектах.
- Секретов в файлах проекта.
