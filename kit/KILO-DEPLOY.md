# План создания производного правила для Kilo

Это узкий механизм создания **одного нового файла**, не установщик Kit и не настройка Kilo.
Он работает только с уже существующими тремя реестрами и каталогом `.kilo/rules`. Он не
создаёт папки или `kilo.jsonc`, не изменяет `AGENTS.md`, не переписывает существующие файлы
и не делает черновики действующими. `scope` уже чем `.` отвергается. Применение возможно
только после просмотра точного плана и отдельного подтверждения. Статус чтения Kilo: `not run`.

```text
python3 -B kit/kilo_deploy.py --workspace /absolute/workspace --profile-root profiles/pilot
```

Процесс принимает по одному UTF-8 JSON на строку и отвечает JSON на stdout:

```json
{"type":"plan","area":"L1","entry_id":"R-1"}
```

План показывает `target`, полный `content`, SHA-256 содержимого и трёх реестров, а также
разовый `ticket`. После проверки владельцем передать **в том же процессе** полный план и
отдельно подтверждённый билет:

```json
{"type":"apply","plan":{"...":"полный ответ plan"},"confirmed_ticket":"подтверждённый билет"}
```

Это схема, а не готовый применимый JSON. `{"type":"cancel"}` отзывает ожидание. Успех —
`created` с относительным путём и SHA-256; файл появляется с именем `kit-l1-<ID>.md` или
`kit-l2-<ID>.md`. Повторный план, если файл уже существует, отказывает — обновление/удаление
существующего материала здесь не реализовано. Убедитесь, что Kilo настроен на чтение этого
каталога, но не изменяйте конфигурацию автоматически; реальный прогон проводится отдельно.

При изменении источника или каталога между планом и применением операция отказывает. В случае
`write_failed` выполняется попытка убрать только созданный этой операцией файл; при
`cleanup_failed`, `cleanup_unsafe` или `created_unverified` результат считать неопределённым:
остановиться, проверить указанный в плане путь и хеш и восстановить его по собственному решению.
Запись не атомарна: пока файл заполняется, другой процесс может увидеть неполное содержимое.
Нет блокировки соседних процессов или полноценной защиты от гонок путей; запускать только при
отсутствии конкурирующих читателей и писателей. Текст инструкции не защищает файлы. Сам билет
не удостоверяет, что владелец видел или одобрил план. Тексты и план
могут содержать данные профиля; не передавайте их в среду без соответствующих прав.
