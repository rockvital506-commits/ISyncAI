# Черновик переносимого профиля

`profile-candidate.json` — предложение для обсуждения, валидный документ L1 схемы v2;
это не ваш активный профиль и не разрешение на установку. Контракт и обе дочерние записи
состояния `draft`: эти тексты не исполняются как действующие правила. Корень `profiles/mvp`
условный; для настоящего профиля нужна доверенная привязка и отдельное согласие на точный план.

В текущем ядре нет операции `draft → active` (`base/OPERATION-PLAN.md`). Нельзя обходить это
ручной заменой состояния или объявлять черновики действующими. До реализации и проверки этого
перехода сквозное применение остаётся `not run`. Реестр является источником данных; файлы среды,
если появятся, должны иметь происхождение и не становиться вторым реестром.
