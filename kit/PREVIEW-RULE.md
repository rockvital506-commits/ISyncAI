# Preview записи из существующей раскладки

`preview_rule.py` соединяет проверенную привязку v2 с рендером. Нужны абсолютный путь к
существующему рабочему дереву, относительный корень выбранного профиля, `L1`/`L2` и ID записи:

```text
python3 -B kit/preview_rule.py --workspace /absolute/workspace --profile-root profiles/pilot --area L1 --entry-id R-1
```

На Windows вместо примера абсолютного пути укажите свой путь, например `D:\\kit-stand`.
Команда читает **только** три реестра, проверяет их физическую привязку и журналы,
проверяет ограничения `RENDER-RULE.md` и выводит JSON с материалом и SHA-256 трёх входных
файлов и результата. В stdout могут присутствовать тексты правил: не запускайте и не
передавайте вывод в чужую среду, если у неё нет разрешения видеть эти данные.

Команда не создаёт проект, не пишет файл, не подключает Kilo, не подтверждает план и не
является защитой от одновременной замены файлов. `authority` и хеши не предоставляют прав.
Не поддерживается целевой scope уже, чем `.`; конфликт текстов без общих `key/value` может
остаться невыявленным. Содержимое источника выбирается вызывающей стороной и не становится
новым реестром.
