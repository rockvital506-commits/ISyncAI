# DomainAgentKit: три слоя и границы кандидата

Манифест формата 2 явно содержит `product: DomainAgentKit`; его проверяют оба проверяющих.
Формат 1 и кандидат до переименования не принимаются текущими проверяющими. Это изменение
исходного кандидата, а не автоматическая миграция данных или подтверждение релиза.
Проектный корень текущей раскладки — `.domain-agent-kit`; прежний путь не читается хранилищем
автоматически. Не переименовывайте реальные данные без отдельного плана и проверенного восстановления.

Подробные границы идентичности и переименования — [IDENTITY.md](IDENTITY.md).

Этот документ описывает кандидата исходного состава, **не выпуск 0.2.0** и не подтверждение
пригодности среды. Манифест `KIT-VERSION.json` содержит только явно перечисленные исходные файлы L0;
он не содержит профилей, проектов, пользовательских журналов, секретов и настроек сред.

| Слой | Назначение | Версия / граница |
|---|---|---|
| L0 | системная схема, операции и документация Kit | неизменяемый состав выпуска; версия кандидата `0.2.0-mvp.71`, это ещё не релиз |
| L1 | переносимый профиль владельца и его история | своя `revision`, не версия продукта; применение и перенос требуют отдельного решения |
| L2 | контракты и правила конкретного проекта | отдельная `revision`; проектные данные не становятся общим профилем автоматически |

Реестры, их поля и связи определены `base/SCHEMA-V2.md`, физические границы — `base/STORAGE-V2.md`.
Ограниченное [копирование L1 в пустой профиль](PROFILE-COPY.md) не является синхронизацией или
перемещением сущности между областями.
`scope` — применимость записи, не адрес хранения. Заявленная `authority` сама не даёт прав.
Данные адаптера не являются вторым реестром; запись файла среды и чтение агентом — отдельные факты.

## Проверка кандидата

Из корня исходного дерева (Python 3.10+, стандартная библиотека):

```text
python3 -B kit/verify_candidate.py
python3 -B kit/verify_candidate.py --pin <заранее-доверенный-sha256-манифеста>
```

Проверка читает файлы и не пишет их. Точный список обязательных файлов задаётся правилами
`verify_candidate.py` и полем `files` манифеста: проверяются перечисленные файлы `kit/base/`
и явно разрешённые дополнительные файлы Kit. Манифест не включает сам себя: его хеш
возвращается отдельно.
Без заранее доверенного `--pin` совпадение хешей доказывает только внутреннюю согласованность,
а не происхождение: одновременная подмена файлов и манифеста не обнаруживается. Эта проверка не
является подписью, авторизацией, защитой от гонок файловой системы или заменой пакета/отката.
Она предназначена для исходного снимка, не для проверки произвольной установленной раскладки.
Отдельная опытная [`snapshot_session.py`](SNAPSHOT-SESSION.md) требует закрытый исходный корень
без дополнительных объектов; это дополнительная проверка только её собственного пути.
